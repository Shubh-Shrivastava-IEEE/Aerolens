# AeroLens -- Aerial Flood Rescue AI
### Nebius x NVIDIA Global AI Hackathon Submission

> **Track:** Physical AI / Best Apps & Agents  
> **Tech Stack:** YOLOv8n (TensorRT on RTX 3050) + NVIDIA Nemotron (via Nebius Token Factory)

---

## What it does

AeroLens is an **offline-first aerial rescue coordination system** for flood disasters.

A drone-mounted GPU module detects stranded people in real time using YOLOv8 accelerated by TensorRT FP16. When a 2G connectivity window opens, compact telemetry packets burst to the cloud where a four-tier NVIDIA Nemotron pipeline performs:

1. **Agentic triage** — dispatches rescue boats, flags hazards, requests medevac via tool-calling
2. **Visual verification** — sends JPEG crops to a Vision-Language model to confirm water depth & structural risk
3. **Zone-wide planning** — 120B reasoning model allocates fleet across simultaneous detections
4. **Mission reporting** — frontier 550B model generates post-mission disaster summary

## NVIDIA Nemotron Integration

All LLM inference routes through **Nebius Token Factory** (`https://api.tokenfactory.nebius.com/v1/`), which provides an OpenAI-compatible endpoint.

| Role | Model | Nebius Model ID |
|------|-------|----------------|
| Agentic Triage + 2G SMS | Primary Dispatcher | `nvidia/Nemotron-3_5-Lightning` |
| Visual Hazard Verifier | Vision-Language | `nvidia/Nemotron-3.5-Super-VL` |
| Multi-Zone Fleet Planner | Reasoning | `nvidia/nemotron-3-super-120b-a12b` |
| Post-Mission Analyst | Frontier | `nvidia/Nemotron-3-Ultra-550b-a55b` |

### How the Nebius client is initialized (in [`nemotron_agent.py`](nemotron_agent.py)):
```python
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("NEBIUS_API_KEY"),
    base_url="https://api.tokenfactory.nebius.com/v1/"
)
```

### Agentic Tool-Calling Loop (Nemotron-Lightning):
```python
response = client.chat.completions.create(
    model="nvidia/Nemotron-3_5-Lightning",
    messages=messages,
    tools=RESCUE_TOOLS,       # dispatch_rescue_boat, flag_zone_hazard, request_medical_evacuation
    tool_choice="auto",
    temperature=0.15,
)
```

### Streaming Output (Nemotron-Ultra-550B):
```python
stream = client.chat.completions.create(
    model="nvidia/Nemotron-3-Ultra-550b-a55b",
    messages=messages,
    stream=True,
)
for chunk in stream:
    print(chunk.choices[0].delta.content, end="", flush=True)
```

## Architecture

```
DRONE (Edge Node - RTX 3050)
  flood_drone.mp4 / images
        |
  YOLOv8n TensorRT FP16
  4 ms/frame @ 640x640
        |
  Person detected (class=0)
        |
  Attach: GPS, water depth, hazard tags
        |
  offline_queue.jsonl (~400 bytes/packet)
        |
  [2G window opens]
        |
NEBIUS TOKEN FACTORY (Cloud)
        |
  +---------------------------------+
  | Nemotron-Lightning (PHASE 1)    |  <-- Agentic tool-calling loop
  |  dispatch_rescue_boat()         |
  |  flag_zone_hazard()             |
  |  request_medical_evacuation()   |
  +---------------------------------+
        |
  +---------------------------------+
  | Nemotron-Super-VL  (PHASE 2)    |  <-- Visual JPEG crop verification
  |  verified_depth_m               |
  |  structural_risk                |
  +---------------------------------+
        |
  +---------------------------------+
  | nemotron-super-120b (PHASE 3)   |  <-- Multi-zone fleet allocation
  |  boat -> victim assignment      |
  +---------------------------------+
        |
  +---------------------------------+
  | Nemotron-Ultra-550B (PHASE 4)   |  <-- Streaming mission report
  |  post-mission summary           |
  +---------------------------------+
```

## Quickstart

### 1. Clone and install
```bash
git clone <your-repo>
cd AeroLens
python -m venv .venv
.venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

### 2. Configure
```bash
copy .env.example .env
# Open .env -> set NEBIUS_API_KEY=nbs-xxxxxxxxxxxxxxxx
```
> Get your key at: https://studio.nebius.com/settings/api-keys

### 3. Verify model IDs on your account
```bash
python verify_models.py
```

### 4. (Optional) Export TensorRT engine -- RTX 3050, ~3 min
```bash
python export_tensorrt.py
```

### 5. Run the full hackathon demo
```bash
# Full 4-model Nemotron demo, synthetic data, streaming output:
python nemotron_agent.py --demo

# With your own video:
python edge_detector.py --video assets/flood_drone.mp4
python nemotron_agent.py --queue offline_queue.jsonl --demo

# With your own images:
python edge_detector.py --image assets/rooftop_photos/
python nemotron_agent.py --queue offline_queue.jsonl --vl --plan --report

# Quick test (no API calls):
python nemotron_agent.py --mock --dry-run
```
